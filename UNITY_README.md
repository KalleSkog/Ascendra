# Unity bouncing ball test

A simple Unity scene has been added so you can test a bouncing ball immediately.

## What to do
1. Open the workspace folder in Unity.
2. Open the scene at Assets/Scenes/BouncingBallScene.unity.
3. Press Play.

The scene creates:
- a camera,
- a bouncing ball with a bright red circle,
- invisible boundary walls so the ball bounces around the screen.
